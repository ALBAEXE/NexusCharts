# v1.8.0 — Automatic error reports
### Added
- If something breaks in the app, from the welcome screen to the chart, the device sends a short technical report automatically, so problems can be fixed even when nobody reports them.
- Technical data only: error message, screen, app version, device type and browser. No name, account or IP address; reports are deleted after 30 days.
