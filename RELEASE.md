# v1.22.0 — Full Style tab for signals and drawings
### Added
- Style tab: every plotshape, plotchar and plotarrow of a script is listed with show/hide, colour and opacity, shape (or character), location, size, text colour and show text; plotarrow has separate up and down colours.
- Style tab: new Drawing objects section to turn boxes, labels, lines, tables and polylines on or off, shown only for the object types the script uses.

### Changed
- Plots and signals declared with editable=false are no longer listed in the Style tab, matching TradingView.

### Documentation
- README updated in 5 languages: new in 1.22.0.
